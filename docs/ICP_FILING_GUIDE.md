# 腾讯云 ICP 备案全流程指引

> **合规 SaaS 想要在大陆 80/443 端口对外可访问, 必须先备案。**
> 全程 1-7 个工作日 (个人备案快, 企业慢), 通过后域名才能指向你的轻量服务器并正常打开。

---

## 0. 备案前 30 秒判断

| 你的情况 | 备案类型 | 预计耗时 | 难度 |
|---------|---------|---------|------|
| 个人开发者 / 个体工商户 | **个人备案** | 3-5 天 | ⭐ 简单 |
| 有营业执照 (公司/个体户) | **企业备案** | 5-10 天 | ⭐⭐ 中等 |
| 备案主体已满 5 个 (腾讯云限制) | 先注销一个再用 | - | - |

**本 SaaS 走个人备案就够** (员工 < 50 的小微企业, 你只需要 1 个域名 + 1 个网站备案号即可)。

---

## 1. 备案前 5 项准备

### 1.1 准备轻量服务器 (必须, 已购可跳)
- 地域: 境内 (上海/广州/北京/南京/成都) 都行, 香港/海外的不能备案
- 购买时长: **≥ 3 个月** (备案期间 + 备案后都要在)
- 已买好服务器, **拿到 IP** (例: `123.123.123.123`)

### 1.2 注册腾讯云账号
- 打开 https://cloud.tencent.com/register
- **手机号 + 实名认证** (个人用身份证, 企业用营业执照)
- 实名认证 1-3 天, **先去认证再去备案**

### 1.3 准备身份证 (个人备案) / 营业执照 (企业备案)
- **个人**: 身份证正反面拍照, 手持身份证照 (腾讯云 App 可以现场拍)
- **企业**: 营业执照、法人身份证、域名证书

### 1.4 准备要备案的域名
- **必须是境内注册商**: 腾讯云 DNSPod / 阿里云万网 / 新网 等
- 国外注册商 (GoDaddy/Namecheap) 的域名**不能**直接备案, 要先转入国内
- 域名所有者要和备案主体一致 (个人备案, 域名所有者是个人身份证姓名)
- 域名**未注册过**或**之前的备案已注销** (一个域名只能备案一次)

### 1.5 下载「腾讯云助手」App
- App Store / 应用市场搜 "腾讯云助手"
- 备案过程要人脸识别 + 上传手持身份证照, 必须用 App

## 2. 备案流程 (8 步, 1-7 天)

### 第 1 步: 进入备案系统
打开 https://console.cloud.tencent.com/beian

点 **「开始备案」** → 选 **「腾讯云」** 标签页 (默认)

### 第 2 步: 选择备案省份
- 选你身份证所在省 (个人) 或营业执照所在省 (企业)
- 选好后, 系统会自动匹配该省的通信管理局规则

### 第 3 步: 填写主体信息

**个人备案**:
| 字段 | 填什么 |
|------|--------|
| 主办单位名称 | 你身份证上的姓名 (例: 张三) |
| 主办单位性质 | 个人 |
| 主办单位证件号码 | 身份证号 |
| 主办单位通讯地址 | 详细到门牌号 |
| 主办单位负责人姓名 | 同上 (个人就是本人) |
| 负责人手机号 | 备案期间能联系到你 |
| 应急联系电话 | 备用手机号 (不能跟负责人同号) |

**企业备案** (个体户也算):
- 公司名称按营业执照一字不差填
- 主体负责人 / 网站负责人可以是法人本人, 也可以授权给员工 (需下载"授权书"模板)

### 第 4 步: 填写网站信息

| 字段 | 填什么 |
|------|--------|
| 网站名称 | 12 字以内, 例: "金诺合规助手" / "小微法务通" |
| 域名 | 你买的域名, 例: `jinluo-fa.com` |
| 服务类型 | 网站应用服务 (默认) |
| 网站语言 | 中文 |
| 备注 | 写 "个人合规风险量化平台" 或类似业务说明 |

⚠️ **网站名称有敏感词库**, 不要用:
- 含 "中国" / "国家" / "官方" / "认证" / "权威" 等大词
- 含 "律师" / "法律" / "律所" (我们要规避, 因为有律师团队但不是律所)
- 模糊化的 "xxx 助手" / "xxx 平台" 都行

### 第 5 步: 上传资料 (在腾讯云助手 App)

App 会让你拍:
1. **身份证正面** (清晰, 边角完整)
2. **身份证反面** (同上)
3. **手持身份证半身照** (能看到脸 + 身份证, 光线足)
4. **域名证书截图** (在域名注册商后台下载 PDF, 截首页)

⚠️ **手持身份证照 80% 的人会拍砸**, 重做要求:
- 脸部占照片 1/3, 不要挡
- 身份证信息完全清晰可读
- 不要戴墨镜/帽子
- 不要用滤镜

### 第 6 步: 腾讯云初审 (1-3 个工作日)
- 腾讯云审核员会看你的资料是否齐全
- 资料不全会打回让你补, **手机短信通知**
- 通过后进入"待提交管局"

### 第 7 步: 提交管局审核 (3-7 个工作日)
- 腾讯云会帮你提交到所在省通信管理局
- **期间不要修改任何备案信息**, 改了要重新排队
- 管局会电话回访 (1 次左右), 问你: "你办这个网站是干什么的? 用的谁的服务器?"
- 接电话时如实说, 别说"做电商" "做支付" 等敏感业务

### 第 8 步: 备案成功
- 工信部 ICP/IP 地址/域名信息备案管理系统: https://beian.miit.gov.cn
- 查到你的备案号 = 备案成功
- 腾讯云会短信 + 站内信通知

## 3. 备案后必做 4 件事

### 3.1 公安备案 (容易忘!)
- 工信部备案通过后, **30 天内**还必须去全国互联网安全管理服务平台备案
- 打开 https://beian.mps.gov.cn
- 用刚才的备案号登录, 填网站信息
- 这个**不是腾讯云代办**, 自己去
- 不做的话, 管局会短信警告, 严重了吊销备案

### 3.2 域名解析指向服务器
DNSPod 控制台: https://console.dnspod.cn/dns/list
- 主机记录: `@` 和 `www`
- 记录类型: `A`
- 记录值: 你的轻量服务器 IP

### 3.3 服务器挂备案号
- 网站所有页面**底部**要挂 ICP 备案号, 链接到 https://beian.miit.gov.cn
- 例: `<a href="https://beian.miit.gov.cn">沪ICP备2026000001号-1</a>`
- 公安备案号 (如果有) 也要挂
- 警察叔叔会来查, 没挂罚款

我已经在合规 SaaS 的 `src/app/layout.tsx` 预留了备案号位, 你备案后填上:

```tsx
// src/app/layout.tsx 末尾加一个 footer
<footer className="py-4 text-center text-xs text-slate-500">
  <a href="https://beian.miit.gov.cn" target="_blank" rel="noreferrer">
    沪ICP备2026XXXXXX号-1
  </a>
</footer>
```

### 3.4 改 .env + 装 SSL
服务器上:
```bash
cd /opt/compliance-saas
# 改 NEXTAUTH_URL 和 WECHAT_PAY_NOTIFY_URL
nano .env
# 把 REPLACE_WITH_YOUR_DOMAIN 改成 your-domain.com
sed -i 's/REPLACE_WITH_YOUR_DOMAIN/your-domain.com/g' /etc/nginx/sites-available/compliance-saas
nginx -t && systemctl reload nginx
pm2 restart compliance-saas

# 装 SSL (Let's Encrypt)
apt install certbot python3-certbot-nginx -y
certbot --nginx -d your-domain.com -d www.your-domain.com
```

## 4. 常见被驳回原因 (90% 的失败案例)

### 4.1 资料问题 (60%)
| 错误 | 怎么改 |
|------|--------|
| 身份证照片不清晰 | 重拍, 边角完整, 字能看清 |
| 手持身份证照脸/证不全 | 重拍, 占照片 1/3 |
| 域名所有者与备案主体不一致 | 改域名所有者 (DNSPod 后台), 或换主体 |
| 手机号/应急号重复 | 填 2 个不同号 |
| 主办单位通讯地址太模糊 | 写到门牌号, 例 "上海市浦东新区张江路 1000 号 5 栋 301 室" |

### 4.2 业务问题 (25%)
| 错误 | 怎么改 |
|------|--------|
| 网站名称含 "律师" "律所" | 改名, 例 "金诺合规助手" |
| 网站名称含 "中国" "国家" | 改成公司/品牌名 |
| 网站备注写 "支付" "金融" | 改成 "合规风险量化" 之类的中性词 |
| 管局电话回访说错话 | 如实说"做小微企业合规 SaaS, 不涉及支付金融" |

### 4.3 服务器问题 (15%)
| 错误 | 怎么改 |
|------|--------|
| 服务器是香港/海外 | 重买一台境内的 |
| 购买时长 < 3 个月 | 续费到 3 个月以上 |
| 服务器已过期/被回收 | 重新买 |


## 6. 几个常见疑问

**Q: 个人备案能经营 SaaS 吗?**
A: 可以, 备案是管"网站", 不管"商业模式"。个人备案的网站放 SaaS 完全合法, 只要不卖金融/医疗/新闻等需要资质的业务。

**Q: 备案主体是个人, 但公司/合伙企业要用, 行吗?**
A: 行, 网站可以用, 收款走公司对公账户或法人个人微信都可以。后续公司成立后, 可以做"备案变更"改成企业。

**Q: 备案要花钱吗?**
A: 工信部备案免费, 腾讯云代备案免费, 公安备案免费。**唯一费用是服务器和域名**。

**Q: 备案号可以挂在多个网站吗?**
A: 1 个备案号下可以挂多个网站 (例: jinluo-fa.com 和 jinluo-fw.com 都挂同一备案号), 但都要在备案时一起报。

**Q: 备案后多久会被复查?**
A: 工信部不定期抽查 (主要看是不是空壳网站、是否违规), 公安备案后会 30 天内做"网安检查" (电话/上门, 主要查日志保留 6 个月以上)。

**Q: 我想做微信支付, 备案主体要跟微信支付商户主体一致吗?**
A: **是的**。所以推荐一开始就用「个体工商户」营业执照备案, 后面接支付顺。
- 没有执照也能接支付, 但要法人个体户 / 微信小程序主体的营业执照
- 个体户执照网上办 3-7 天, 大部分省免费

## 7. 备案通过后 — 让用户上你网站

1. 浏览器打开 https://your-domain.com → 看到登录页
2. 用 `demo@example.com` / `demo1234` 登录
3. 改管理员密码 (现在演示账号的密码是公开的, 上线前必改)
4. 把这个链接发给目标用户: "用你的公司邮箱注册, 前 7 天免费"

后端种子脚本会创建 demo 账号, 第一次登录后, 建议**立即**改密码 (或直接删掉 demo 账号, 让用户自己注册)。

## 8. 紧急情况

**备案被驳回 3 次以上**: 联系腾讯云备案客服 95716 转 1, 让他们电话指导修改。

**管局审核电话没接到**: 会在 2 小时后再打, 还不行就发短信让你回复确认。

**域名被墙了 / 服务器被封**: 先查腾讯云站内信, 99% 是备案问题或被举报了。处理: 登录 https://console.cloud.tencent.com/beian 查状态。
